# DokumentFoto – einfache Android-App

Diese App ist absichtlich schlicht:

1. **Dokument fotografieren**
2. Foto in der App ansehen
3. **Als JPG speichern** oder **als PDF speichern**

Die App nutzt die normale Kamera-App des Android-Geräts. Deshalb braucht sie keine eigene Kameraoberfläche und keine Speicherberechtigung.

## Projekt öffnen

- Android Studio öffnen
- **Open** wählen
- den Ordner `DokumentFoto` öffnen
- Gradle synchronisieren lassen
- auf einem Android-Gerät starten

## Voraussetzungen

- Android Studio mit Android SDK 35
- Java 17
- Android 8.0 oder neuer (minSdk 26)

## Version 1.0

- Ein Dokumentfoto pro Vorgang
- automatische Bildausrichtung
- Vorschau
- JPG-Export
- A4-PDF-Export

Eine spätere Version kann Mehrseiten-PDF, automatischen Zuschnitt und Kontrastverbesserung bekommen.
